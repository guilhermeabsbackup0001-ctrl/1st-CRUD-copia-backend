## Sobre o projeto

Sistema CRUD completo (Create, Read, Update, Delete) para gerenciamento de usuários, desenvolvido como aplicação de **página única (SPA)**.

A aplicação utiliza uma arquitetura desacoplada, com frontend e backend independentes, comunicando-se através de uma API REST.

---

## Funcionalidades

* Cadastro de usuários
* Listagem em tabela
* Busca dinâmica em tempo real
* Edição de dados
* Exclusão de usuários
* Paginação dos registros
* Reset automático do banco a cada 1 hora

---

## Destaques técnicos

* Arquitetura **full stack desacoplada**
* Aplicação **SPA (Single Page Application)**
* Comunicação via **API REST**
* Implementação de **busca em tempo real**
* Sistema de **paginação eficiente**
* Estratégia de **reset automático do banco** para evitar spam e acúmulo de dados
* Deploy em ambiente de produção
